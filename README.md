# نظام إدارة الموظفين والرواتب 💼

تطبيق ويب متكامل (PWA) لإدارة الموظفين والرواتب والنفقات التشغيلية — يعمل على الجوال والكمبيوتر وبدون إنترنت.

## ✨ المميزات

### 👥 إدارة الموظفين
- **موظفون بالراتب الشهري**: راتب ثابت + حوافز + بدلات − سلف − خصومات
- **موظفون بالقطعة**: حساب تلقائي (عدد القطع × سعر القطعة) + إضافات وخصومات
- بحث سريع، تعديل، حذف، معاينة فورية لصافي الراتب

### 💰 مسير الرواتب الشهري
- إدخال عدد القطع والحوافز والسلف لكل شهر على حدة
- حساب تلقائي لصافي المستحق لكل موظف
- ملخص إجمالي + طباعة مسير الرواتب

### 🧾 النفقات التشغيلية
- فئات جاهزة: إيجار، كهرباء، ماء، صيانة، تسويق، وقود، وغيرها
- تصفية شهرة وسنوية + إجماليات تلقائية

### 📈 التقارير المالية
- تقرير ربح/خسارة شهري: الإيرادات − (الرواتب + النفقات)
- تفاصيل كاملة قابلة للطباعة

### 💾 البيانات
- تُحفظ محلياً على جهازك (localStorage) — لا حاجة لخادم
- تصدير/استيراد نسخة احتياطية JSON
- يعمل بدون إنترنت بعد أول تحميل (Service Worker)

## 📱 التثبيت على الجوال
1. افتح رابط التطبيق في المتصفح
2. **أندرويد (Chrome)**: ⋮ ← "إضافة إلى الشاشة الرئيسية"
3. **آيفون (Safari)**: زر المشاركة ← "إضافة إلى الشاشة الرئيسية"
